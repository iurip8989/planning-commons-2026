# 心中山 Planning Commons 2026

グローバル都市地域演習 2026 の事前学習・現地調査用資料サイトです。

- 対象地: 台北市・心中山地区
- 表示言語: 日本語 / 繁體中文 / English
- 公開版: Cloudflare Pages / GitHub Pages（閲覧用バックアップ）
- 現地調査資料: Cloudflare D1 と R2 に保存

## 現地調査コモンズ

- 写真、PDF、短い動画をアップロード後すぐに共有
- 写真を最大辺 1920px 程度に軽量化し、地図用サムネイルも生成
- HEIC / HEIF はブラウザ上で JPEG に変換
- 調査日、学生グループ、観察カテゴリーで絞り込み
- 地図上の写真マーカーと資料カードを連動
- アップロードした本人による改名・削除、授業参加者による標星

Cloudflare Pages の Bindings は `DB`（D1）と `UPLOADS`（R2）。Variables and secrets には `UPLOAD_CODE` と `ADMIN_CODE` を Secret として設定する。データベース表は最初の API アクセス時に自動作成・更新される。

## 著作権・引用方針

外部サイトや書籍の本文・画像は転載せず、短い要約、出典リンク、授業用の分析軸として整理しています。原文・図版・写真が必要な場合は各資料の原本を参照してください。
